# BeiDou Resource Workbench

统一的本地资源管理系统。源码、页面、测试和启动入口均收口在本目录，当前包含：

- 地图与怪物工作台：资源对比、预览、诊断和安全编辑。
- IMG 节点编辑器：同步编辑客户端 `.img` 与服务端 `.img.xml`。
- 任务管理：筛选和维护任务四件套、关联脚本与任务物品。
- 物品管理：浏览非装备物品，对比 TMS 节点并执行兼容复制和增量维护。

## 启动

```bash
rtk tool/resource-workbench/start-resource-workbench.sh
```

默认访问 `http://127.0.0.1:8790`。四个模块共用同一个进程和端口；模块首次打开时加载，之后切换会保留筛选、已打开文件和编辑状态。

## 地图与怪物

- 浏览客户端 `.img`、服务端 `.img.xml` 和导出 `.json` 的节点树。
- 对比地图或怪物文件，并标记一致、修改和单侧节点。
- 组合地图场景，预览怪物、NPC、传送门和怪物动作。
- 对 XML 执行局部增删改，对客户端 IMG 执行受约束的增量修改。
- 提供现代资源兼容分析和地图崩溃诊断。

## IMG 节点

- 同步编辑一对客户端 `.img` 与服务端 `.img.xml`。
- 支持 `SubProperty`、`Null`、数字、字符串、`Vector` 和 `UOL`。
- Canvas、Sound 等媒体节点可以查看、重命名和删除，但不导入媒体。
- 首次修改会创建 `.web-editor.bak`；外部文件发生变化时拒绝覆盖。

## 任务管理

- 按任务地区、起止 NPC、名称或 ID 筛选任务。
- 同步编辑 `QuestInfo`、`Check`、`Act`、`Say` 的客户端 IMG 与服务端 XML。
- 成套新增或删除任务，支持单记录原始 XML 高级编辑。
- 自动关联任务脚本、起止 NPC 脚本及主目录/中文目录版本。
- 搜索和选择任务物品，预览本地装备或 Item IMG 图标。

## 物品管理

- 只收录消耗、设置、其他／掉落、现金、宠物和特殊物品，明确排除装备。
- 统一搜索本地与 TMS 目录，可直接筛选“仅 TMS／待迁移”“两边都有”“仅本地”。
- 同屏对比当前项目节点与最终旧端迁移投影，并保留 TMS 原始节点供核对。
- TMS Canvas 会解析 `_inlink`／`_outlink` 后转换为旧端 GMS ARGB4444。
- 待迁移物品可先修改名称、描述和兼容投影节点，再作为新物品写入当前项目；已有物品也支持本地节点增删改。
- 普通分片物品支持兼容迁移、受确认的更新、删除和本地文本维护。
- 宠物单文件资源当前只读，避免未经证明的整文件覆盖。

四个模块沿用原有的二进制安全和 XML 局部写入逻辑，不使用全树重写器修改现有客户端 IMG。
