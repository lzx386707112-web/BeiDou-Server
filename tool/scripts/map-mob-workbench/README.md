# Map & Mob Workbench

本地地图与怪物资源工作台，参考 `png2canvas` 的 Flask 启动方式实现。

## 启动

```bash
rtk tool/scripts/map-mob-workbench/start-map-mob-workbench.sh
```

默认访问 `http://127.0.0.1:8775`。

## 功能

- 浏览客户端 `.img`、服务端 `.img.xml` 和导出 `.json` 的节点树。
- 通过目录选择器浏览并选择 B 对比文件，同时保留路径手动输入。
- 同 ID 地图默认使用 `../TMS/MapleStory-IMG/Data` 作为 B，并并排显示 A/B 节点信息与地图预览。
- 对比任意两个地图或怪物文件，按一致、修改、仅主文件、仅对比文件标记差异。
- 组合地图背景、图块和对象，显示真实怪物、NPC、传送门贴图，并支持拖动查看地图。
- 点击地图中的怪物、NPC、传送门、场景对象或地形线，可自动展开并定位对应节点。
- 按原始 `delay` 播放怪物动作帧。
- 对 XML 节点执行增、删、改，保持目标节点之外的 XML 文本不变。
- 对客户端 IMG 的数字、等长字符串和向量执行原位字节修改。

## 写入边界

客户端 IMG 不支持增删节点，也不会使用全树序列化器。IMG 编辑只在编码长度不变时写入原始槽位；其他修改应先编辑服务端 XML，再通过经过审查的原始记录增量迁移脚本同步客户端。

写入默认启用预演。关闭“仅预演”后才会落盘，首次落盘前的副本保存在 `.workbuddy/map-mob-workbench-backups/`。
