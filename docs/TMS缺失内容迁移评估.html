先说结论

  • 绝大多数「没有」是真没有，但大多数也不该迁。182 个完全缺失簇里，约 三分之二属于 273 专属系统、083 后新增职业剧情、或需要神秘力量/进化系统——这三类在 GMS 083 客户端上根本表达不出来，不是工作量问题。
  • 真正值得做的是「传统机制」那一池。打怪 / 收集 / 护送 / 阶段通关 / Boss 战 / 小游戏，083 端全都能表达，服务端也有 EventInstanceManager + 121 个 event 脚本的既有框架。
  • 性价比最高的一组是「地图有缺口、但资源零新增」：龍騎士（50 图 / 0 新怪 / 0 新 NPC）、夏摩斯护送（51 图 / 0 / 0）、CWKPQ boss 段（18 图 / 0 / 0）、維京飛行船（5 图 / 0 / 0）。迁地图即可，不用碰 Mob.wz。
  • 最大的一块「金矿」是苦痛迷宮：全 TMS 被 83 条任务引用（引用数第一），BeiDou 已迁约 26%，实缺约 116 张，只需 8 个新怪——贵在图多，不贵在机制。
口径校准（避免误判）：覆盖率按地图 ID 比对，但 BeiDou 历史上从 TMS 迁过的图会换新 ID。因此额外做了中文地图名交叉校验：绝大多数簇名称命中为 0（确认真缺失），只有三组有存量——苦痛迷宮 26%、黑色天堂 11%、神秘河后段 8%。这三组在下文按「实缺张数」计算，不是按 ID 全缺。
