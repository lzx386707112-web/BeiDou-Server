# 北斗修仙进阶系统 · 玄天十境

## 设计原则
- **战力公式不变**: `(STR+DEX+INT+LUK)×10 + (WATK+MATK)×50 + (WDEF+MDEF)×1`
- **战力天花板**: 10亿 (1,000,000,000)
- **玄天十境**: 10个境界，凡界五境+仙界五境
- **装备驱动**: 战力主要来自装备属性，涅槃AP为辅助
- **不同起始等级**: 不同境界涅槃后回到不同等级

---

## 一、战力公式回顾

```
战力 = (STR+DEX+INT+LUK)×10 + (WATK+MATK)×50 + (WDEF+MDEF)×1
```

**权重**: WATK/MATK权重50（最高），四维属性权重10，防御权重1（最低）

**装备槽位**: 约40个（含时装、骑宠等）

## 四、涅槃AP积累（辅助战力）

每次涅槃从起始等级练到255级，获得AP：

| # | 境界 | 起始等级 | 练级量 | 每次AP |
|---|------|---------|--------|--------|
| 1 | 乾元玄阶 | Lv1 | 254级 | ~1,270 |
| 2 | 坤极玄域 | Lv30 | 225级 | ~1,125 |
| 3 | 天元玄境 | Lv60 | 195级 | ~975 |
| 4 | 玄枢天宿 | Lv100 | 155级 | ~775 |
| 5 | 星墟玄阙 | Lv140 | 115级 | ~575 |
| 6 | 太玄星河 | Lv180 | 75级 | ~375 |
| 7 | 苍玄帝宿 | Lv210 | 45级 | ~225 |
| 8 | 鸿蒙玄墟 | Lv230 | 25级 | ~125 |
| 9 | 无极天机 | Lv245 | 10级 | ~50 |
| 10 | 无上天帝 | Lv255 | 0级 | ~0 |

**AP对战力的贡献**:
- 9转累计约11,430 AP
- 全部加主属性: 11,430 × 10 = 114,300 CP
- 相比装备战力（数亿~数十亿），AP贡献很小
- **涅槃的主要价值是境界提升和奖励，不是AP本身**

## 六、游戏节奏

### 6.1 第1~2转（凡界入门）
```
Lv1 → 练到Lv30 → 第1次涅槃 → 练到Lv60 → 第2次涅槃
```
- 境界：乾元玄阶 → 坤极玄域
- 战力：0 → 100,000
- 装备：白装 → 绿装
- 时间：约1~2天

### 6.2 第3~4转（凡界成长）
```
Lv1 → 练到Lv100 → 第3次涅槃 → 练到Lv140 → 第4次涅槃
```
- 境界：天元玄境 → 玄枢天宿
- 战力：100K → 10M
- 装备：蓝装 → 紫装
- 时间：约3~5天

### 6.3 第5~6转（仙界入门）
```
Lv140 → 练到Lv180 → 第5次涅槃 → 练到Lv210 → 第6次涅槃
```
- 境界：星墟玄阙 → 太玄星河
- 战力：10M → 200M
- 装备：橙装 → 金装
- 时间：约1周

### 6.4 第7~8转（仙界进阶）
```
Lv210 → 练到Lv230 → 第7次涅槃 → 练到Lv245 → 第8次涅槃
```
- 境界：苍玄帝宿 → 鸿蒙玄墟
- 战力：200M → 2B
- 装备：金装+系统 → 顶级装
- 时间：1~2周

### 6.5 第9~10转（仙界巅峰）
```
Lv245 → 练到Lv255 → 第9次涅槃 → 练到Lv255 → 第10次涅槃
```
- 境界：无极天机 → 无上天帝
- 战力：2B → 10B+
- 装备：极限装 → 终极装
- 时间：2~4周

## 十、实现建议

### 10.1 核心改动
1. **数据库**: 创建境界配置表和角色境界表
2. **涅槃脚本**: 改造为动态起始等级+属性保留
3. **境界突破NPC**: 实现境界突破逻辑
4. **战力系统**: 不改公式，但需要考虑境界显示

### 10.2 装备系统扩展（如需达到10亿）
要让战力能达到10亿，可能需要扩展装备系统：
- 增加装备品质等级（顶级/极限/终极）
- 增加强化上限（+20/+25）
- 增加潜能/星之力上限
- 或引入新的装备属性系统

### 10.3 优先级
1. 先实现境界框架（涅槃+突破+显示）
2. 再调整装备数值以匹配境界区间
3. 最后平衡各境界的游戏体验
