# 修仙进阶 · 每次境界突破操作详解

## 通用突破流程

每次境界突破时，系统自动执行以下操作：

```
1. 验证条件 → 2. 扣除材料 → 3. 执行突破 → 4. 发放奖励 → 5. 全服通告
```

---

## 凡界四境

### 凡人 → 练气（入门修仙）

**突破条件：**
- 等级 ≥ 50
- 战力 ≥ 500
- 涅槃次数 ≥ 1

**突破操作：**
1. **等级重置**：等级回到 1 级（保留职业）
2. **属性保留**：保留当前装备，不重置属性点
3. **发放奖励：**
   - 境界称号「练气修士」
   - 初级修为丹 × 10（使用后获得大量经验）
   - 偷学技能点 +1
   - 境界礼包（随机蓝装一件）
4. **解锁功能：**
   - 解锁「修炼日常」任务（每日杀怪任务，奖励经验+修为值）
   - 解锁初级副本入口

- 等级 ≥ 200
- 战力 ≥ 30,000
- 涅槃次数 ≥ 7
- **完成飞升任务链**（击败5个凡界BOSS）

**飞升任务链：**

3. **解锁功能：**
   - 解锁神秘河全部区域
   - 解锁仙界日常任务
   - 解锁仙界副本
   - 角色名变为金色显示

## 关键设计说明

### 1. 等级重置机制
- **凡界**：每次突破重置等级到1级（保留职业和装备）
- **飞升后**：等级保持200级不再重置（仙界靠战力驱动）
- **原因**：凡界需要反复练级积累战力，仙界靠装备和强化

### 2. 被动技能设计
每个境界的被动技能提供**永久属性加成**，随境界提升而增强：
- 凡界：主要加HP
- 仙界：加HP + 全属性 + 攻击力
- 这样低战力玩家也有基础生存能力

### 3. 强化券设计
- 使用100%成功券，避免强化失败挫败感
- 每个境界的券对应不同强化上限
- 玩家需要多个境界积累才能达到满强化

### 4. 修为丹设计
- 使用后获得大量经验，加速升级
- 数量逐境界增加，后期境界升级更快
- 避免玩家在高等级时枯燥练级
