# 北斗修仙 · 进阶系统设计方案

## 一、现有系统分析

### 1.1 当前涅槃系统
- **条件**: Lv255 + 涅槃石×30 + 高级魔方×10 + 5W点券
- **等级**: 涅槃后等级回到 **200级**（不是1级）
- **每次涅槃收益**: 多55级属性点（约275 AP）+ 涅槃脚本给的AP + 偷学技能点+1
- **累计收益**: 10次涅槃 = 额外2750+ AP，角色属性远超未涅槃玩家
- **上限**: max_reborn_count = 10次
- **核心**: 涅槃次数是战力的第一驱动力，每次涅槃角色永久变强

### 1.2 当前战力系统
- **计算公式**: `STR×10 + DEX×10 + INT×10 + LUK×10 + WATK×50 + MATK×50 + WDEF×1 + MDEF×1`
- **权重**: 攻击属性远高于防御（物攻/魔攻权重50，四维属性权重10，防御权重1）
- **排行**: 支持前100名战力排行

## 四、九境修仙体系设计

### 4.1 两界九境总览

```
┌─────────────────────────────────────────────────────┐
│ 阶段一 · 凡界（冒险岛主大陆）战力 0 ~ 30,000         │
│                                                     │
│  凡人 → 练气 → 筑基 → 金丹                           │
│  0~500  500~3K  3K~10K  10K~30K                     │
├─────────────────── 渡劫飞升 ────────────────────────┤
│ 阶段二 · 仙界（神秘河）战力 30,000+                   │
│                                                     │
│  元婴 → 化神 → 炼虚 → 合体 → 大乘 → 仙尊            │
│  30K~80K 80K~200K 200K~500K 500K~1.5M 1.5M~5M 5M+  │
└─────────────────────────────────────────────────────┘
```

### 4.2 涅槃机制说明（重要）

**当前涅槃系统**：
- 涅槃后等级回到 **200级**（非1级）
- 每次涅槃 = 从200练到255 = 多55级的属性点
- 每级给5 AP + `level_up_ap_gain` 配置值
- 每次涅槃额外获得约 **275+ AP**
- 10次涅槃 = 额外 **2750+ AP** 全部加到主属性
- 涅槃脚本本身也给 `(涅槃次数+1)×50` AP

**结论**：涅槃次数是战力的核心驱动力，每次涅槃都让角色永久变强。

### 4.3 各境界详细设定

#### 凡界四境

| 境界 | 涅槃次数 | 等级要求 | 战力参考 | 解锁内容 |
|------|---------|---------|---------|---------|
| **凡人** | 0 | 1~200 | 0~2,000 | 初始状态，探索新手村 |
| **练气** | 1~2 | 200~255 | 2,000~8,000 | 解锁组队任务、初级副本 |
| **筑基** | 3~5 | 200~255 | 8,000~20,000 | 解锁远征队、中级地图 |
| **金丹** | 6~7 | 200~255 | 20,000~40,000 | 解锁高级BOSS、飞升资格 |

#### 仙界五境+仙尊

| 境界 | 涅槃次数 | 等级要求 | 战力参考 | 对应区域 |
|------|---------|---------|---------|---------|
| **元婴** | 8 | 200~255 | 40,000~80,000 | 消逝的旅途 |
| **化神** | 9 | 200~255 | 80,000~150,000 | 啾啾岛/梦都拉克兰 |
| **炼虚** | 10 | 200~255 | 150,000~300,000 | 阿尔卡纳/莫拉斯 |
| **合体** | 10 | 255 | 300,000~800,000 | 艾斯佩拉 |
| **大乘** | 10 | 255 | 800,000~2,000,000 | Tenebris/Hotel |
| **仙尊** | 10 | 255 | 2,000,000+ | 全境征服 |

**说明**：
- 凡界主要靠**涅槃次数**驱动境界提升
- 仙界涅槃已满(10次)，靠**装备强化**继续提升战力
- 战力为参考值，实际以涅槃次数为主要门槛

### 4.3 境界突破机制

#### 渡劫飞升（凡界→仙界）
- **条件**: 金丹境 + Lv200 + 战力≥30,000 + 完成飞升任务链
- **飞升任务**: 击败各凡界BOSS（扎昆、暗黑龙王、女皇等）
- **奖励**: 解锁神秘河入口、境界称号、飞升礼包

#### 境界突破（每个小境界）
- **自动晋升**: 战力达到阈值时自动提升境界
- **手动确认**: NPC处确认突破，获得境界奖励
- **突破奖励**: 称号、属性加成、专属道具

## 五、初级实施计划

### 5.1 第一阶段：基础框架（1-2周）

**目标**: 将现有涅槃系统改造为修仙进阶系统

1. **修改战力计算公式**
   - 增加等级权重：`等级×2` 加入战力计算
   - 增加涅槃次数权重：`涅槃次数×500`
   - 保持装备战力不变

2. **创建境界配置表**
   - 新建数据库表 `cultivation_realm`
   - 字段：境界名、战力下限、战力上限、等级要求、涅槃要求、奖励配置

3. **修改涅槃NPC脚本**
   - 将"九转涅槃"改为"境界突破"
   - 每次涅槃显示当前境界和下一境界
   - 突破时自动计算并显示新境界

### 5.2 第二阶段：境界系统（2-3周）

1. **境界显示系统**
   - 角色名前显示境界称号（如「筑基」玩家名）
   - 战力面板增加境界进度条
   - 境界排行榜（与战力排行合并）

2. **境界奖励系统**
   - 每个境界突破奖励：
     - 凡人→练气：初级功法技能书
     - 练气→筑基：中级功法+属性丹
     - 筑基→金丹：高级功法+装备强化券
     - 金丹→元婴：飞升大礼包+神秘河通行证

3. **飞升任务链**
   - 设计6-8个任务节点
   - 击败指定BOSS
   - 收集特定材料
   - 完成剧情对话

### 5.3 第三阶段：内容扩展（3-4周）

1. **境界专属技能**
   - 每个境界解锁1-2个被动技能
   - 技能效果随境界提升而增强

2. **修仙副本**
   - 每个境界对应一个专属副本
   - 副本掉落境界突破材料

3. **修仙日常任务**
   - 每日修炼任务（杀怪、收集、副本）
   - 任务奖励修为值，用于境界加速

## 六、技术实现要点

### 6.1 数据库设计

```sql
-- 境界配置表
CREATE TABLE cultivation_realm (
    id INT PRIMARY KEY AUTO_INCREMENT,
    realm_name VARCHAR(20) NOT NULL,
    realm_order INT NOT NULL,
    min_combat_power INT NOT NULL,
    max_combat_power INT NOT NULL,
    min_level INT NOT NULL,
    min_reborns INT NOT NULL,
    reward_items TEXT,
    reward_buffs TEXT,
    description TEXT
);

-- 角色境界记录表
CREATE TABLE character_realm (
    character_id INT PRIMARY KEY,
    current_realm_id INT NOT NULL,
    realm_progress FLOAT DEFAULT 0,
    last_breakthrough DATETIME,
    total_breakthroughs INT DEFAULT 0,
    FOREIGN KEY (character_id) REFERENCES characters(id),
    FOREIGN KEY (current_realm_id) REFERENCES cultivation_realm(id)
);
```

## 八、总结

### 核心理念
- **以战力为核心驱动力**，取代单纯等级驱动
- **两界分离**，前期在冒险岛主大陆积累，后期进入神秘河
- **九境渐进**，每个境界有明确目标和奖励
- **保留涅槃**，但将其融入修仙体系

### 预期效果
1. 延长游戏寿命，增加长期目标
2. 自然引导玩家从主大陆过渡到神秘河
3. 增加社交性（组队飞升、境界竞争）
4. 保留原有涅槃机制的同时增加新玩法
