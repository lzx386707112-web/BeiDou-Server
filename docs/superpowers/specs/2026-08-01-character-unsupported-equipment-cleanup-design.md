# 非目标职业装备清理设计

## 目标

从当前 `Character` 资源中删除用户指定的 13 类非目标职业装备，同时保留双刀、所有未点名职业以及任何存在实际业务引用的物品。删除前必须建立可验证、可完整恢复的本地备份。

## 删除范围

采用已完成引用审计和图文确认的精确 ID 清单，不使用宽泛编号段。共删除 299 个物品 ID：

| 职业分类 | 数量 |
| --- | ---: |
| 古迹猎人 | 38 |
| 精灵游侠 | 15 |
| 幻影 | 129 |
| 恶魔系 | 18 |
| 爆破手 | 12 |
| 龙神（含龙装备） | 18 |
| 剑豪 | 16 |
| 阴阳师 | 19 |

| 尖兵 | 5 |
| 凯撒 | 2 |

| 神之子 | 24 |

用户所说的“龙身”按清单中的“龙神”分类处理，包含该分类下的龙装备。

明确保留：

- 双刀副刀 `134xxxx` 清单中的 98 件。
- 飞侠共用主刀 `133xxxx`，不纳入任何删除清单。
- 未点名的其他职业装备。
- 已确认存在引用的 `1052463`、`1902024`、`1342011`。

## 备份设计

删除前在仓库根目录的 `.codex-backups/` 下创建带时间戳的备份目录。备份内容包括：

1. 299 个客户端 `clien/Data/Character` IMG 文件。
2. 对应的 299 个服务端 `gms-server/wz/Character.wz` XML 文件。
3. 修改前的客户端 `clien/Data/String/Eqp.img`。
4. 修改前的 `gms-server/wz/String.wz/Eqp.img.xml`。
5. 修改前的 `gms-server/wz-zh-CN/String.wz/Eqp.img.xml`。
6. 含 ID、名称、职业、资源相对路径和原始 SHA-256 的清单。

资源和名称表按仓库相对路径打包进单个 `tar.gz`。在删除开始前验证压缩包可列出、文件数量符合预期，并写出压缩包自身的 SHA-256。备份目录保持未跟踪状态，不纳入提交，避免把大量二进制备份写进版本历史。

## 删除流程

1. 从已审计清单生成精确的 299 ID manifest，并逐项确认客户端、服务端文件都存在。
2. 再次对 299 个精确 ID 执行代码、脚本、NPC、商店、掉落、迁移文件和当前数据库引用检查。发现真实业务引用的 ID 自动移出删除集合并报告，不强行删除。
3. 创建并验证备份。
4. 删除最终无引用 ID 对应的客户端 IMG 和服务端 XML。
5. 仅从三份 `Eqp` 名称表中移除最终删除 ID 对应的节点；保留文件中所有其他既有改动和格式。
6. 不修改职业逻辑、掉落逻辑、商店逻辑或其他非资源文件。

## 异常处理

- 任一目标缺少客户端或服务端对应文件：停止删除并报告不一致。
- 备份压缩包无法验证或数量不符：停止删除。
- 发现新的真实引用：该 ID 保留，其余无引用 ID 可继续处理；最终报告实际删除数量和保留原因。
- 名称表无法精确定位唯一节点：停止修改名称表，避免宽泛文本删除。

## 验证标准

- 最终删除集合的客户端和服务端资源都已不存在。
- 三份名称表均不再包含最终删除 ID，且未改动其他名称节点。
- 双刀 98 件、`133xxxx` 主刀、未点名职业以及三个引用物品仍存在。
- 精确 ID 引用复查中不存在指向已删除 ID 的真实业务引用。
- 客户端与服务端剩余资源集合保持镜像一致。
- 备份压缩包可读取，清单和 SHA-256 校验文件齐全，可按原相对路径恢复。
