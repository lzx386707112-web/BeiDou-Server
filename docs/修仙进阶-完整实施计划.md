```javascript
// 新增境界倍率常量
const REALM_MULTIPLIERS = {
    1: 1.0,   // 凡人
    2: 1.5,   // 练气
    3: 2.0,   // 筑基
    4: 3.0,   // 金丹
    5: 4.0,   // 元婴
    6: 5.5,   // 化神
    7: 7.0,   // 炼虚
    8: 8.5,   // 合体
    9: 10.0   // 大乘
};

// 新增：计算含境界倍率的总战力
function calculateTotalCombatPower(player) {
    var equipCP = calculateEquipmentCombatPower(player);
    var baseCP = calculateBaseCombatPower(player);
    var realmId = getPlayerRealm(player);
    var multiplier = REALM_MULTIPLIERS[realmId] || 1.0;
    return Math.floor((baseCP + equipCP) * multiplier);
}

// 新增：计算基础属性战力（等级+涅槃积累）
function calculateBaseCombatPower(player) {
    var str = player.getStr() - 4; // 减去初始4点
    var dex = player.getDex() - 4;
    var int_ = player.getInt() - 4;
    var luk = player.getLuk() - 4;
    return (str + dex + int_ + luk) * 10;
}
```

### 4.1 创建境界突破NPC脚本
**文件**: `gms-server/scripts-zh-CN/npc/cultivation_breakthrough.js`

**功能**:

```javascript
// 核心逻辑框架
function start() {
    var realmId = getPlayerRealm();
    var realm = getRealmConfig(realmId);
    var nextRealm = getRealmConfig(realmId + 1);
    
    // 显示当前境界信息
    var text = `当前境界：${realm.realmName}\r\n`;
    text += `境界倍率：${realm.realmMultiplier}x\r\n`;
    text += `下一境界：${nextRealm.realmName}\r\n\r\n`;
    
    // 显示突破条件
    text += `突破条件：\r\n`;
    text += `- 涅槃次数 ≥ ${nextRealm.minReborns}\r\n`;
    text += `- 战力 ≥ ${nextRealm.minCombatPower}\r\n`;
    text += `- 等级 ≥ ${nextRealm.maxLevel}\r\n\r\n`;
    
    // 检查是否满足条件
    if (canBreakthrough()) {
        text += "#L0#突破到下一境界#l\r\n";
        cm.sendSimple(text);
    } else {
        text += "不满足突破条件\r\n";
        cm.sendOk(text);
    }
}

function levelBreakthrough() {
    // 执行突破
    var nextRealmId = getPlayerRealm() + 1;
    setPlayerRealm(nextRealmId);
    
    // 发放奖励
    giveBreakthroughRewards(nextRealmId);
    
    // 全服通告
    broadcastBreakthrough(nextRealmId);
}
```

## 附录C：风险评估

### 技术风险
1. **数据迁移风险**: 现有玩家数据需要初始化境界
   - 缓解方案: 先在测试环境验证，准备回滚脚本

2. **性能风险**: 境界倍率计算可能影响战力排行榜性能
   - 缓解方案: 优化SQL查询，增加缓存

3. **兼容性风险**: 修改战力公式可能影响现有功能
   - 缓解方案: 保留旧公式作为备选，逐步切换

### 游戏平衡风险
1. **数值膨胀风险**: 境界倍率可能导致数值过大
   - 缓解方案: 预先计算各阶段数值，确保合理

2. **玩家体验风险**: 涅槃起始等级变化可能影响体验
   - 缓解方案: 提供新手引导，说明新机制
