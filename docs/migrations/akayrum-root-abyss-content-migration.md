# 阿卡伊勒与鲁塔比斯任务、Boss、远征迁移

## 迁移范围

- 鲁塔比斯任务：`30000`、`30002–30013`、`30027`。
- 阿卡伊勒任务：`31165–31180`。
- 普通鲁塔比斯远征：半半、皮埃尔、血腥女王、贝伦。
- 阿卡伊勒远征与任务用阿卡伊勒分身事件。
- 历史上曾恢复贝伦区域地图 `105200410–105200419`，以及剧情入口地图
  `910700200`、`910700300`；这些地图已在 2026-08-14 按“只保留 Boss 和任务数据”的要求退役。
- 同步任务道具、勋章、NPC、怪物、Reactor 和字符串资源；地图与 `Bgm29` 资源已退役。

服务端 `wz`、`wz-zh-CN`、两套脚本目录和客户端 `clien/Data` 必须一起部署，
不能只更新服务端。

## 兼容策略

- 保留项目原有的兼容版阿卡伊勒 `8860000`，只补充任务用分身 `8860001`；
  不用数据包里的同名 Boss 覆盖现有机制。
- 保留项目已经改进过的 `rootabyssOUT.js`、`outrootaBoss.js`。
- 普通鲁塔比斯远征统一为至少 1 人、125 级；阿卡伊勒为至少 1 人、140 级。
- 删除源脚本中项目不存在的方向演出和伤害排行 API，缺失 Reactor 更新改为
  null-safe，避免剧情或 Boss 击杀流程中断。
- `MobSkill 183/184/187` 与项目已有 Will、Magnus、Seren 兼容技能共用编号。
  按怪物 ID 分流鲁塔比斯行为；保留现有 `187/1` 数据，并固定 Magnus 的原有
  35% 伤害，避免迁移反向破坏现有 Boss。
- 21 个缺失或需替换的 MobSkill 等级只迁入服务端 XML。旧客户端不能新增
  `188/191/201/202/203` 顶层类型，也不能把 `128/133/145/170` 等技能直接跳到
  高等级；这样会在启动阶段提示“不正确的游戏数据”。客户端 `MobSkill.img`
  必须保持迁移前版本，审计会检查这项兼容约束。
- 数据包内夹带的妖精学院、列娜海峡等内容不在本次迁移范围内。

## 复现与验证

迁移脚本可重复执行，首次执行前的目标文件备份在
`/private/tmp/akayrum-root-abyss-content-backup`：

```bash
rtk python3 tool/scripts/migration/migrate_akayrum_root_abyss_content.py
```

静态审计会解析服务端 XML 和客户端 IMG，并检查任务、地图、怪物、NPC、字符串、
共享资源、入口 portal、服务端 MobSkill 完整性、客户端 MobSkill 原版兼容约束、
脚本兼容条件和 Java 枚举：

```bash
rtk python3 tool/scripts/audit/audit_akayrum_root_abyss_content.py
```

部署时先应用 Flyway 数据库迁移，再同步服务端与客户端资源，并重启服务端使远征
枚举和 MobSkill 处理逻辑生效。
