# 神秘河怪物掉落与旧端任务迁移

## 迁移范围

- 83 种在 152 张神秘河地图中实际刷新的怪物。
- 23 个可在旧端闭环运行的任务，覆盖消逝的旅途、啾啾艾尔兰、拉契尔恩、
  阿尔卡娜、魔菈斯和艾斯佩拉。
- 8 个任务物品及其客户端图标、客户端名称、服务端 Item/String 数据。
- 21 个现存任务 NPC、17 种任务目标怪物；没有新增地图、NPC 或怪物资源。

## 掉落规则

- 所有 83 种怪物补充金币、超级药水 `2000005` 和特殊药水 `2000006`。
- MSS206 的概率以 10000 为基数；普通 `100` 转换为本项目的 `10000`。
- 本服将上述两种普通药水的掉率再提高 10 倍至 `100000/999999`（约 10%）；
  金币与任务物品概率保持不变。
- 8 个收集任务物品按任务号限制，只有任务进行中才掉落，概率为 `500000`。
- 未迁移 MSS206 中旧客户端不存在的核心、现代药水、箱子、矿石等物品，
  防止客户端捡取或显示未知道具时异常。

## 命中兼容

现代来源中的怪物回避值为 `205–930`，直接放入旧客户端后，部分怪物即使命中
达到 999 仍会频繁 MISS。152 张地图实际使用的 83 种怪物已统一设置为
`info/eva=200`；同级物理满命中约需 734，999 命中有足够余量。低等级角色越级
攻击仍保留旧端原有的等级差命中惩罚。

修复工具：`tool/scripts/migration/normalize_arcane_river_mob_eva.py`

数据库迁移：
`gms-server/src/main/resources/db/migration/V2.1.42__add_arcane_river_mob_and_quest_drops.sql`

## 任务兼容策略

任务名、描述、NPC、目标、任务物品和原有经验优先取自本地 TMS 繁中
`Quest/QuestData`，没有凭空编写主线对白。只对以下旧端不兼容内容做了简化：

- 移除 `startscript`、`endscript`、`sayEx`、`npcSpeech` 和 `infoex`。
- 移除自动接取、现代演出、缺失地图传送及未安装 NPC 的任务。
- 将任务流程改为普通 NPC 接取、击杀或收集、NPC 完成。
- 收集任务完成时按需求数量扣除任务物品。
- 缺少直接经验奖励的任务按区域补充固定经验，不发放现代装备或核心。

原任务号 `341xx–345xx` 超过 Java 有符号 short 上限。客户端封包仍然是原来的
16 位，服务端接收处改为无符号解析，兼容范围为 `0–65535`，现有低编号任务不变。

- 83 个怪物掉落、8 条任务掉落和 8 个任务号限制一致。
