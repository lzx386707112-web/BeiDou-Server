# 奇袭者五、六转攻击技能迁移

## 范围与 ID

TMS v280 奇袭者五、六转直接攻击技能迁移到旧端空技能书 `1512.img`。客户端生成 30 个节点，
其中 6 个可施放入口会在登录或转职时补至 30 级，其余为枪雷连击动作、周期落雷和 Origin
多阶段重放节点。

默认等级同时覆盖两条路径：登录时对现有1511/1512角色补至技能等级30、精通等级30；转职调用
`setMasteries` 时也直接写入30/30，不再走旧四转技能的“0级、精通10级”分支。

| 本地 ID | TMS ID | 技能 | 满级攻击参数 | 范围 `lt..rb` |
| ---: | ---: | --- | --- | --- |
| `15121000` | `400051015` | 海龙螺旋 | `780% x3`, 10目标 | `(-275,-145)..(275,55)` |
| `15121002` | `400051058` | 枪雷连击 | `1430% x5`, 4目标 | `(-650,-400)..(450,300)` |
| `15121015` | `15141006` | 台风VI | `859% x5`, 8目标 | `(-550,-320)..(80,120)` |
| `15121016` | `15141007` | 海神降临VI | `1380% x7`, 15目标 | `(-550,-330)..(550,300)` |
| `15121017` | `15141500/01` | 浪驰雷掣 | `1390% x5` / `1370% x7`, 15目标 | `(-1200,-800)..(1200,800)` |
| `15121019` | `15141502/03` | 疾浪歼灭 | `6160% x12` / `6510% x15`, 15目标 | `(-1200,-800)..(1200,800)` |

神雷合一是主动 Buff，落雷和海波VI是攻击触发被动，海神护体是护盾，雷神枪击是累计连锁自动触发，
均不作为普通可施放入口授予。消灭VI、霹雳VI及其隐藏霹雳闪节点已按要求删除。

巨鲨狂浪因旧客户端无法稳定进入新版弹体构造路径而移除；原生鲨鱼波资源恢复，不再做热键别名或
节点替换。其余迁移技能使用拳套近战封包，职业技能所有权和实际装备仍由原有客户端及服务端攻击流程检查。

## 持续攻击与多阶段

- 海龙螺旋：严格使用 `subTime=240ms` 和最多 100 次攻击额度，在 `0..23760ms` 重放 100 段；
  范围跟随人物当前位置，死亡、离线或换图后停止。入口的 `effect0/effect` 按真实时间边界合成
  21段、1620ms，并按源帧循环至最后一次攻击的23760ms；启动特效11段、960ms，结束特效
  16段、960ms，怪物命中7帧、630ms。
  后续攻击改用隐藏节点 `15121021`，只播放逐怪命中，不再每240ms重复整套施放特效；
- 枪雷连击：使用服务端权威连续输入状态机。每次按键只推进当前一式，60秒内最多12次，
  180ms内的重复输入不推进；一至六式循环两轮。入口 `effect` 是透明占位，服务端按实际计数
  回送 `15121022..15121033` 隐藏视觉节点，每个节点把当前招式与对应的1至12计数图合入
  标准 `effect`，服务端用 `SHOW_*_EFFECT` type 1显式触发本机与他人视角的主视觉、普通落雷、终式和
  巨大落雷，再用隐藏攻击包
  播放该式逐怪 `hit`。每次有效命中优先在最多3个不同存活目标上
  分别触发 `1555% x4` 普通落雷。第12次后自动在相对 `510ms` 触发 `1990% x7` 终式，
  再于 `840/1170/1500ms` 触发3次 `2145% x6` 巨大落雷；死亡、离线、换图、60秒超时或旧轮次
  generation 会取消残留阶段。源 `delayedTime=390/270ms` 分别映射为旧端支持的
  `hitAfter=390/270ms`；
- 台风VI：21帧、1260ms施放效果和7帧、420ms命中效果；保留源 `time=95`、`x=2`、
  `y=3`、`u=250`；
- 海神降临VI：人物效果16帧、960ms，命中20帧、1200ms；全屏层保留最初透明帧后为
  45帧、2940ms MCV，并把源 `effectFlash` 的8段黑/白闪屏按时间边界合入视频；
- 浪驰雷掣：完整读取 `multiAttackInfo`，前段 32 次，时间范围 `300..4200ms`；雷海冲击
  62 次，时间范围 `4680..7140ms`。两个阶段的逐怪命中均为10帧、600ms，完整保留随机位置、
  随机角度、覆盖伤害编号和命中音效概率；
- 疾浪歼灭：猛攻 11 次，`180..780ms`；激流 18 次，`1620..2310ms`。没有合并或抽帧攻击段。
  人物前后景为11帧、660ms，两个阶段的命中均为9帧、540ms。10张静态 `number` 图按后十次
  开场攻击的 `240..780ms` 合入通用 `effect`；随机位置仍走旧端原生字段。覆盖伤害编号、随机角度
  和按概率切换命中音效属于新版渲染器字段，旧端没有一一对应接口，分别退化为普通伤害数字、
  原朝向命中特效和默认命中音效。

## 效果节点兼容审计

审计以旧端全部 `Skill.wz` 实际节点和字段为准，而不是只看TMS节点是否成功写入：

| TMS节点/字段 | 旧端结论 | 兼容方式 |
| --- | --- | --- |
| `effect` | 支持 | 保持人物锚点、帧延迟、origin、Alpha和Z层，普通攻击直接播放 |
| `hit` | 支持 | 保持逐怪变体；`randomHitOrigin` 是旧端原生字段 |
| `special` | 支持，但普通攻击不自动触发 | 海龙螺旋结束阶段由 `SHOW_*_EFFECT` type 2显式触发 |
| `end` | 旧端全部技能中不存在 | 精确合成为隐藏节点 `15121021/special`，在23760ms显式触发 |
| `number` | 旧端全部技能中不存在 | 枪雷12张分别合入12个服务端视觉节点的 `special`；疾浪10张按源攻击时点合入 `effect` |
| `delayedTime` | 不支持 | 映射为旧端同义字段 `hitAfter` |
| `screen/screen2/screen3`、`effectFlash` | 不支持新版视频/闪屏节点 | 合成为VP9 Alpha MCV，并由FIELD_EFFECT标记和DLL播放 |
| `waveEffectInfo`、`distortionEffectInfo`、`trembleEffectList` | 不支持新版相机/Shader节点 | 主画面保留在MCV；旧端没有可安全复用的地图相机/噪声Shader接口，不写入无效节点 |
| `randomHitAngle/randomHitFlip` | 不支持 | 保留可用的随机原点，使用源默认角度/朝向帧 |
| `onCoverFieldDamage`、`hitSoundProb/hitSoundMod` | 不支持 | 使用普通伤害数字和默认命中音效，不影响段数和伤害结算 |

旧端已有54个根 `mob`、38个根 `special`，但没有任何根 `number` 或 `end`；旧 `hit` 字段包含
`hitAfter`、`randomHitOrigin`、`pos`，不包含上述新版角度、覆盖数字和概率音效字段。这些统计同时作为
兼容选择的依据。海龙螺旋开始和结束效果由服务端检查人物仍在线、存活且未换图后再播放。

满级基础伤害、攻击段数、目标数、MP和 `lt/rb` 均直接与TMS表达式比较；源冷却仍单独校验，
最终按本地规则覆盖为浪驰雷掣、疾浪歼灭10秒，其余技能0秒。另外补齐
海龙螺旋的攻击间隔/额度/刷新参数、枪雷连击全部终结参数及二级范围、
台风VI子参数，以及两个Origin的持续更新、无冷却区间、DOT、无视防御和Boss参数。
所有节点的 `info`/`info2` 也逐字段迁移并校验：海龙螺旋、
落雷、巨大落雷、海神降临VI、浪驰雷掣及雷海冲击保留 `ignoreCounter=1`；所有范围攻击都明确写入
`areaAttack=1`。TMS高版本 `info/type` 超出旧端类型范围的节点只把 `type` 兼容归一为 `1`，其余标志
保持源值。所有逐怪 `hit` 节点的 `randomHit`、随机原点、延迟、角度、翻转、Z层级和覆盖伤害字段均参与校验。

TMS根节点的每个整数标志也经过白名单审计。所有 `weapon` 和 `weapon2` 明确移除；
`invisible` 按本地入口/内部阶段重新设置。
`vSkill`、`origin`、`holding`、`preloadEff`、
`processtype` 等依赖新版V矩阵、Origin或蓄力状态机的标志不复制到旧端；相同行为由本地默认满级、
MCV和服务端多阶段重放实现。生成器会在TMS出现任何尚未分类的新根参数时直接失败，避免静默漏迁移。

持续与 Origin 攻击使用近战重放框架。每个时间点读取对应隐藏节点自己的伤害百分比、攻击段数、
目标上限和矩形，重新选取范围内存活怪物并优先 Boss；人物离线、死亡或换图后任务停止。海龙螺旋
跟随人物，两个 Origin 固定在施法位置。枪雷每次按键使用本次真实目标；普通落雷优先使用这些目标，
终式和巨大落雷在各自触发时从人物当前位置重新选取存活目标。阶段自己的伤害、攻击次数、目标上限、
命中特效和延迟仍逐项保持TMS参数。

## MCV 大特效

所有高帧数 `screen` / `Canvas#Video` 大层都从 Skill WZ 移出，使用与魂骑士、炎术士、夜行者、
风灵使者相同的 `7x5` FIELD_EFFECT 标记和 `BeiDouVideo.dll` 播放：

| 技能 | 文件 | 帧数 | 时长 | 输出画布 |
| --- | --- | ---: | ---: | --- |
| 海神降临VI | `Data/Video/god-of-sea-vi.mcv` | 45 | 2940ms | `1280x720` |
| 浪驰雷掣 | `Data/Video/wave-riding-thunder.mcv` | 131 | 7860ms | `1280x720` |
| 疾浪歼灭 | `Data/Video/swift-annihilation.mcv` | 55 | 3300ms | `1280x720` |

海神降临VI由 41 帧普通 Canvas（含源透明等待帧）与8段源闪屏时间线合成为45帧。浪驰雷掣先按
全部帧的 Alpha 有效并集裁掉源 `1800x1200` MCV 的透明边，再按风灵全屏方式等比放大、居中裁切到
`1280x720`。疾浪歼灭的 `screen`、`screen2`、`screen3` 三条 55/55/51 帧视频共同计算同一个裁剪框，
避免同步层错位，再按 Alpha 顺序合成。两个成品都会解码复查 Alpha 并集必须覆盖完整
`(0,0)..(1280,720)`，不再只检查文件头分辨率。

补丁必须同时包含 `BeiDouVideo.dll`、`Data/Map/Effect.img` 和上表三个 MCV；缺少任一项都会使
对应技能仍能结算伤害，但看不到全屏层。

必须跟随人物坐标、左右朝向或弹体移动的局部动作与命中特效仍保留为 ARGB4444 Canvas；这些不是
全屏大层，改成当前全视口 MCV 会丢失空间锚点并导致攻击位置错位。

## 客户端与生成

统一 `DawnWarriorSkillCompat.dll` 允许 `15121000..15121033` 进入主动技能/视觉分发，使服务端回送
的隐藏攻击包能读取标准 `effect`；键盘分发仍截止 `15121021`，因此新增 `15121022..15121033`
不能绑定或主动施放，只能由服务端权威回送。
三个入口启动对应 MCV，隐藏重放节点保持不可见。巨鲨狂浪相关键盘别名、远程构造 Hook、服务端
处理和资源节点均已删除，原生鲨鱼波保持原样。
奇袭者视频在主动技能分发时入队，并在下一帧D3D8 Present、即近战攻击状态初始化完成后启动；
服务端FIELD_EFFECT标记仍作为第二条触发/绘制链。
旧端的通用近战入口之后还有四个 Brandish 专用分类点。迁移技能如果在这些点被伪装为 Brandish，
`action=fist` 也会被剑/斧动作规则拒绝。DLL 仅从这四个 Brandish 分类点移除奇袭者迁移 ID，使其像
原生 `15111004` 一样按拳甲近战分支执行；枪雷连击各阶段使用旧端存在的 `alert5` 角色动作。
原生完整验证函数保持执行，MP/HP消耗、技能状态初始化及
其他条件不被跳过。
MCV仍优先在FIELD_EFFECT标记层绘制；若客户端没有画出该标记，DLL会在D3D8 Present前兜底绘制，
保证浪驰雷掣等全屏层不会只结算伤害而无画面。

```bash
rtk python3 tool/scripts/patch-skill/export_thunder_breaker_ms.py
rtk python3 tool/scripts/patch-skill/patch_thunder_breaker_v_vi.py
rtk python3 tool/client-video/export_thunder_breaker_mcvs.py
rtk bash tool/client-debug/dawn-warrior-skill-compat/build.sh
rtk python3 tool/scripts/patch-skill/patch_thunder_breaker_v_vi.py --validate-only
rtk tool/client-video/build/mcv_probe clien/Data/Video/god-of-sea-vi.mcv
rtk tool/client-video/build/mcv_probe clien/Data/Video/wave-riding-thunder.mcv
rtk tool/client-video/build/mcv_probe clien/Data/Video/swift-annihilation.mcv
```

迁移器验证 30 个技能节点、无额外武器资源限制、满级攻击参数、范围、持续时间、完整视觉时间线、
逐怪命中元数据、`info/info2`、可见性、服务端 XML 和三个视频标记。服务端攻击时序也直接回查TMS：
海龙螺旋100次/240ms，枪雷连击12次输入/180ms下限、逐次落雷与自动终结，以及两个Origin
的完整 `multiAttackInfo`。服务端使用 JDK 21 编译；兼容 DLL 构建为 32 位 PE。
