# 冒险家战士五、六转攻击技能迁移

## 范围

本迁移以 TMS v280 为源，只迁移英雄、圣骑士、黑骑士的攻击类五转/六转技能到旧四转技能书
`112.img`、`122.img`、`132.img`。纯增益、纯防御和纯被动技能不加入技能栏；会主动或持续造成
伤害的召唤、领域和攻击型 Buff 保留。可施放入口只通过“技能中心 -> 冒险家五、六转攻击技能”
脚本补至技能等级/精通等级 30，内部攻击阶段保持隐藏，只由服务器回放。

| 职业 | 可施放入口 | 隐藏攻击阶段 |
| --- | --- | --- |
| 英雄 | `1121012..14`, `1121020`, `1121023`, `1121025`, `1121030` | `1121015`, `1121021..22`, `1121024` |
| 圣骑士 | `1221015..16`, `1221020`, `1221027`, `1221030` | `1221017`, `1221021..22`, `1221028..29`, `1221031..32` |
| 黑骑士 | `1321011`, `1321015`, `1321018`, `1321020`, `1321022`, `1321025` | `1321016`, `1321019`, `1321021`, `1321026` |

英雄的剑影分身使用兼容区间内的 `1121020`。迁移器会从首次迁移备份精确恢复旧端怪物磁铁
`1121001` 的客户端、服务端和文本节点，避免两个技能共用 ID 导致剑影分身无法发出近战攻击包。
已使用旧版本脚本的英雄再次运行学习脚本时，会清理旧剑影分身、斗气本能、灵气之刃 VI、
剑士意念 VI 及其隐藏阶段的键位，并删除旧 `1121001` 学习记录后授予新的剑影分身。

## 学习与键位

脚本按 `V_VI_ACTIVE_ATTACKS` 的顺序一次授予当前冒险家职业的全部可施放攻击入口，并依次覆盖绑定
到 `A-Z`。英雄、圣骑士和黑骑士分别使用 `A-G`、`A-E`、`A-F`；隐藏攻击阶段不授予也不上键。
`Character.setMasteries` 不再初始化这些技能的等级或精通等级，脚本学习前没有可手动分配的精通
上限，脚本学习后已经是 30/30，因此技能面板不能通过 SP 单独加点。圣骑士重新学习时会清除已删除的
祝福之锤、骑士冲击波 VI、神圣审判 VI、神圣冲击 VI、神圣烙印 VI、正义审判及裁决记录和旧键位。骑士团的
授予逻辑不受影响。

## 参数与攻击时间轴

生成器直接计算 TMS 等级 30 表达式，强制比较 `damage`、`attackCount`、`mobCount`、`mpCon`、
冷却和 `lt/rb`。`d(...)` 使用向下取整，`u(...)` 使用向上取整。燃烧灵魂之剑的冷却存放在
TMS `x=120` 而不是 `cooltime`。本服明确覆盖英雄入口冷却：圣剑降临为 10 秒，其余可施放入口
全部为 0 秒；隐藏攻击阶段仍为 0 秒。燃烧灵魂之剑入口按 TMS `time=20` 播放，固定形态攻击节点
保留源 `time=120`、`w=1000ms` 元数据，但服务端重放以入口 20 秒为限。雷神战锤的
`cooltimeMS=2500` 是三枚战锤的充能回复，不写成整技能冷却。黑骑士明确覆盖灭世永恒之枪和
黑暗契约为 10 秒，其他保留入口及全部隐藏阶段为 0 秒。圣骑士明确覆盖圣域展开和圣狮之主为
10 秒，其余保留入口及全部隐藏阶段为 0 秒。

服务端按 TMS 参数处理以下持续和多阶段攻击：

- 剑之幻象：12 次斩击 `1320..2670ms`，5 次爆发 `2790..3000ms`；
- 燃烧灵魂之剑：生成固定位置的旧端召唤物，每 1000ms 攻击，持续 20 秒；
- 圣剑降临、圣域展开、圣狮之主、灭世永恒之枪、黑暗契约：完整使用源 `multiAttackInfo`，按阶段
  切换到对应隐藏节点；Origin 攻击范围固定在施法坐标；
- 圣十字架先播放 900ms 准备动作，再每 150ms 攻击 4 秒并播放 960ms 收尾；雷神战锤在
  960ms 命中，并于 1170ms 触发爆炸；
- 圣域领域从 420ms 起每 300ms 攻击 30 秒；鬼神之击 VI 保留 4 次主击，正义崛起按
  `SecondAtom enableDelay=960ms` 在 `960..1320ms` 播放 4 次追加攻击；
- 枪刺旋风每 140ms 攻击 4 秒，随后在 `4150..4360ms` 播放 8 次终结。

神圣审判/烙印、闇之标枪等节点依赖后续按键、职业计数或特定攻击触发。旧端没有对应现代状态机，
因此保留完整隐藏资源，不把它们错误地改成每次施放都无条件追加伤害。

## 局部特效与怪物命中

角色 `effect/effect0`、召唤、弹体、`special`、`mob` 和逐怪 `hit` 均从 TMS `_Canvas` 解出，
重编码为旧端 GMS ARGB4444，并保留帧延迟、origin 和层级。嵌套攻击特效做了以下显式展开：

- 燃烧灵魂之剑：把现代 `summon` 转成旧端识别的 `summoned/stand/attack1/die` 状态，保留
  `attackAfter=270`、8 怪范围和标准 `hit/0`。服务端生成 20 秒固定召唤物；召唤攻击包只负责
  出现、待机、攻击与命中演出，实际伤害仍由服务端时间轴结算，避免重复伤害；
- 剑影分身：`effect` 与 `effect0` 按各自帧延迟并行合成。TMS 的 `effect0/0` 是 1320ms 空帧，
  大剑光应在 1320ms 首击时出现；迁移器保留这段空白，不再把未来的大剑光提前显示并停留，
  同时保留斩击和爆发的逐怪 `hit`；
- 断罪之枪：把 `effect`、延迟出现的宽幅 `special` 和 `shootobj/layerList/b1` 投射物按 TMS
  时间轴及直线位移合成同一旧端 `effect`。旧近战分支没有原生 `ball` 先例，因此不依赖不会播放
  的 `ball` 节点；
- 圣十字架：完整串联 `prepare`、4 秒蓄力阶段和 `keydownend2`，总视觉时长 5860ms；持续伤害改用
  无角色动画的隐藏节点 `1221032`，并把 `hit/hit2` 两套怪物命中特效合入旧端 `hit/0`；
- 雷神战锤：保持旧端近战入口，角色侧保留召唤环和投射光带；按实际命中目标生成最多 4 个短时
  固定召唤对象，分别播放 TMS 锤体飞行、爆炸和逐怪 `hit`，避免远程入口对圣骑士武器做错误校验；
- 正义崛起：从 `Etc/SecondAtom.img` 与 `_Canvas/SecondAtom.img` 提取技能 `custom` 列表中的
  满功率 70 号原子，转换为会随攻击方向移动的 18 帧/1080ms 普通 `effect`；
- 圣狮之主：`effect/effect0/special` 三层按时间合并，局部动画完整播放 2760ms；
- 黑暗契约：按源时间轴并行合成 `effect/effect2/effect3/effect4`，恢复 27 帧/2460ms 的完整局部
  演出；所有合成画布统一缩放到旧端安全的 `1280x720` 纹理边界内，避免客户端资源校验报错。

黑暗灵气及终结、闇灵冲击、冈格尼尔之击 VI、追随者冲击 VI 及其黑暗士气阶段已从客户端、
服务端、技能文本、学习脚本和旧键位清理列表中删除。

## MCV 大动画

新版 `screen/video` 层由导出器按源延迟合成，输出为 VP9 颜色轨加独立 Alpha 轨。多轨长度不同时
按时间边界取当前帧合成，不按帧号硬配对。

| 技能 | 文件 | 帧数 | 时长 | 画布 |
| --- | --- | ---: | ---: | --- |
| 圣剑降临 | `Data/Video/spirit-caliber.mcv` | 117 | 7020ms | `1280x720` |
| 圣域展开 | `Data/Video/sacred-bastion.mcv` | 89 | 5340ms | `1280x720` |
| 圣狮之主 | `Data/Video/dominus-obrion.mcv` | 47 | 2820ms | `1280x720` |
| 灭世永恒之枪 | `Data/Video/dead-space.mcv` | 103 | 6180ms | `1280x720` |
| 黑暗契约 | `Data/Video/dark-halidom.mcv` | 41 | 2460ms | `1280x720` |

圣域展开、圣狮之主和灭世永恒之枪会先按源视频的 Alpha 联集裁切，再以 cover 模式放大到
`1280x720`；可见演出覆盖完整屏幕，而不是保留源文件四周的大块透明区域。

`Map/Effect.img` 为五项演出增加 `7x5` FIELD_EFFECT 标记；`DawnWarriorSkillCompat.dll` 在主动技能
分发时启动对应 MCV，并让这些本地低 ID 继续走旧端近战路径。局部角色/怪物特效仍由 Skill WZ
按世界坐标绘制，不并入全屏视频。

英雄入口均使用 `brandish1`。兼容 DLL 将 `1121012..1121030` 的主动技能、内部攻击阶段统一送入
旧端 Brandish 的动作类型、视觉偏移、状态切换和命中分支；否则旧客户端会把高于原 Brandish ID 的
技能送入无动作分支，表现为点击键位没有反应。`1121020` 剑影分身因此与其他英雄迁移技能一样
使用 Brandish 分支，`1121023` 圣剑降临在 Brandish 分流之外继续启动 MCV。

## 生成与验证

```bash
rtk python3 tool/scripts/patch-skill/patch_explorer_warrior_v_vi.py --job all
rtk python3 tool/client-video/export_explorer_warrior_mcvs.py
rtk python3 -m unittest tool/scripts/patch-skill/test_explorer_warrior_v_vi_contract.py -v
rtk python3 -m unittest tool/scripts/patch-skill/test_explorer_skill_grant_contract.py -v
rtk bash tool/client-debug/dawn-warrior-skill-compat/build.sh
rtk env JAVA_HOME=/opt/homebrew/opt/openjdk@21/libexec/openjdk.jdk/Contents/Home \
  PATH=/opt/homebrew/opt/openjdk@21/bin:/opt/homebrew/bin:/usr/bin:/bin:/usr/sbin:/sbin \
  mvn -q -DskipTests compile
```

迁移器最终验证英雄 11 个节点/435 张 Canvas、圣骑士 14 个节点、黑骑士 10/276。契约测试另外核对
攻击类可见 ID、隐藏节点、TMS 参数、Java 时间轴、删除技能、MCV 尺寸/时长/Alpha 和 DLL
映射。最终仍需在 Windows/Winlator 客户端逐项实测角色动作、左右朝向、怪物锚点、他人视角与
FIELD_EFFECT/MCV 的实际层级。
