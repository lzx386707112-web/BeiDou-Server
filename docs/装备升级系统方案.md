# 装备升级系统方案 (全新设计 v4)

## 一、设计理念

### 核心原则
- **100%成功率** — 条件满足即升级，无概率失败
- **极严格条件** — 每阶段10~20种材料，数量最低120，涵盖对应等级段全部怪物掉落
- **装备献祭** — 高阶升级需消耗低阶装备
- **任务系统** — 每阶段2~5个无等级限制任务，阶段间不重复
- **分支选择** — 套服(Longcoat) vs 上衣+裤子(Coat+Pants) 两条路线
- **武器多样** — 每职业多条武器升级链可选

### 任务选取原则
1. 只选 **无 `lvmin`/`lvmax` 等级限制** 的任务
2. 每阶段 **2~5个任务**，等级越高任务越多
3. 阶段间 **任务不重复**
4. 优先选取 **对应等级区域** 的任务（如低级选维多利亚岛、中级选天空之城/玩具城、高级选时间神殿等）
5. 自定义主线任务(600001~600007)由脚本控制等级，可正常使用
