# 北斗修仙 · 进阶系统设计方案 v3

## 设计约束
- **战力天花板**: 8亿 (800,000,000)
- **等级机制**: 不一定每次回1级，不同境界不同起始等级
- **属性保留**: 每次涅槃属性永久保留
- **装备加成**: 装备是战力的重要组成部分

---

## 一、战力构成分析

### 当前公式
```
战力 = (STR+DEX+INT+LUK)×10 + (WATK+MATK)×50 + (WDEF+MDEF)×1
```

### 战力来源拆分
```
总战力 = 基础属性战力 + 装备战力

基础属性战力 = 等级属性 + 涅槃积累AP → 乘以境界倍率
装备战力 = 全身装备属性加权 → 乘以装备境界倍率
```

### 引入境界倍率（核心改动）
每个境界提供一个**境界倍率**，乘以该境界的所有战力：

| 境界 | 境界倍率 | 说明 |
|------|---------|------|
| 凡人 | 1.0x | 基础 |
| 练气 | 1.5x | 初窥门径 |
| 筑基 | 2.0x | 小有所成 |
| 金丹 | 3.0x | 凡界巅峰 |
| 元婴 | 4.0x | 初入仙界 |
| 化神 | 5.5x | 仙界中期 |
| 炼虚 | 7.0x | 仙界后期 |
| 合体 | 8.5x | 接近巅峰 |
| 大乘 | 10.0x | 终极境界 |

## 三、涅槃（转生）机制

### 3.1 涅槃规则

| 当前境界 | 涅槃后起始等级 | 每次练级量 | 每次获得AP |
|---------|-------------|-----------|-----------|
| 凡人 | Lv1 | 254级 | ~1,270 |
| 练气 | Lv30 | 225级 | ~1,125 |
| 筑基 | Lv60 | 195级 | ~975 |
| 金丹 | Lv100 | 155级 | ~775 |
| 元婴 | Lv140 | 115级 | ~575 |
| 化神 | Lv180 | 75级 | ~375 |
| 炼虚 | Lv210 | 45级 | ~225 |
| 合体 | Lv230 | 25级 | ~125 |
| 大乘 | Lv245 | 10级 | ~50 |

**设计逻辑**：
- 凡界每次涅槃从1级开始，练级量大，AP收益高
- 仙界每次涅槃起始等级越来越高，练级量减少，但境界倍率补偿
- 大乘每次只练10级，但10倍境界倍率让战力依然增长显著

### 3.2 涅槃奖励

每次涅槃固定获得：
- 偷学技能点 +1
- 修为丹（加速下次练级）
- 转生礼包

涅槃脚本额外AP：`(当前转数+1) × 50`

## 六、游戏节奏

### 6.1 第1~2转（凡界新手期）
```
Lv1 → 练到Lv30 → 第1次涅槃（回Lv1）→ 练到Lv60 → 第2次涅槃（回Lv1）
```
- 体验：熟悉游戏，探索主大陆
- 战力：0 → 30,000
- 时间：约1~2天

### 6.2 第3~4转（凡界成长期）
```
Lv1 → 练到Lv100 → 第3次涅槃 → 练到Lv140 → 第4次涅槃
```
- 体验：解锁远征队、高级地图
- 战力：30,000 → 500,000
- 时间：约3~5天

### 6.3 第5~6转（仙界入门期）
```
Lv140 → 练到Lv210 → 第5次涅槃 → 练到Lv230 → 第6次涅槃
```
- 体验：进入神秘河，解锁新系统
- 战力：500,000 → 30,000,000
- 时间：约1周

### 6.4 第7~9转（仙界巅峰期）
```
Lv230 → 练到Lv245 → 第7次涅槃 → 练到Lv255 → 第8/9次涅槃
```
- 体验：追求极限装备，挑战终极BOSS
- 战力：30,000,000 → 800,000,000
- 时间：2~4周

## 七、技术实现要点

### 7.1 战力公式修改

```javascript
// 新增境界倍率
const REALM_MULTIPLIERS = {
    1: 1.0,   // 凡人
    2: 1.5,   // 练气
    3: 2.0,   // 筑基
    4: 3.0,   // 金丹
    5: 4.0,   // 元婴
    6: 5.5,   // 化神
    7: 7.0,   // 炼虚
    8: 8.5,   // 合体
    9: 10.0   // 大乘
};

function calculateTotalCombatPower(player) {
    // 1. 装备战力
    var equipCP = calculateEquipmentCombatPower(player);
    
    // 2. 基础属性战力（等级+涅槃积累）
    var baseCP = calculateBaseCombatPower(player);
    
    // 3. 境界倍率
    var realmId = getPlayerRealm(player);
    var multiplier = REALM_MULTIPLIERS[realmId] || 1.0;
    
    // 4. 总战力 = (基础属性 + 装备) × 境界倍率
    return Math.floor((baseCP + equipCP) * multiplier);
}
```
