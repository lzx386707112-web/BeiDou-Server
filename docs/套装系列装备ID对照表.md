# BeiDou 套装系列 × 装备 ID 对照表

> **数据来源（只读）**
> 1. `clien/Data/String/Eqp.img` —— 客户端装备显示名（玩家实际看到的名称）；
> 2. `gms-server/src/main/resources/equipment-catalog/catalog.json` —— 后端「装备预览」目录（16,454 件，部位/属性）。
>
> **图例**：✅ 库中存在 · ❌ 缺失 = 客户端与后端目录中均查无此装备（含原表格标注「（缺）」的部件）。
> **套装构成**：系列内**服装相同、武器多种** ⇒ 每个系列 = 服装 1 套 ＋ 武器 N 件。
> **每件武器 ＋ 全套服装 = 1 个套装**，因此**一个系列包含 N 个套装**（N = 该系列可用武器种数）。
> **同名多版本**：同一名称的装备常对应多个版本 ID（如法弗纳系列每把 3 个 ID），按 **1 种名称 = 1 件** 计，多个 ID 并列展示。
> **⚠️ 提示**：原表格未列武器、但库内确有武器件的系列，会单独标注并给出补列后的套装数。
> **说明**：「服装件」为各套装共用；「武器件」逐件列出并编号。「备注」列仅在库内名称与表格写法不同、或需特别提示时填写。
> **套装加成**：按原表录入，件数为激活该档效果所需的穿戴件数（见各系列末尾「套装加成」节）。
> **同前缀共用加成**：原表把若干同族系列并作一组给加成（如「所有班·雷昂系列」「芬撒里尔系列」），已分发到每个具体系列。
