# 北斗修仙 · 进阶系统设计方案 v2

## 核心机制变更

### 涅槃改为"轮回修炼"
- 每次涅槃等级回到 **1级**
- **属性保留**（不重置AP、不重置已加属性）
- 每次轮回 = 从1级练到255级 = 254级 × 5AP = **1270+ AP** 永久积累
- 涅槃次数越多，角色越强，但每次都要从1级重新练起
- 每次轮回选择一个"修炼路线"（对应不同等级区间）

### 境界体系：九境 × 九转

**九境** = 等级区间（决定你在哪张地图修炼）
**九转** = 涅槃次数（决定你的基础属性强度）

```
九境：凡人 → 练气 → 筑基 → 金丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘
      Lv1   Lv30   Lv60   Lv100  Lv140  Lv180  Lv200  Lv230  Lv255

九转：第1转 → 第2转 → 第3转 → ... → 第9转（满转）
      1次涅槃  2次涅槃  3次涅槃        9次涅槃
```

## 二、九转设计（涅槃次数）

每次涅槃 = 一次"转生"，属性永久保留累积。

| 转生 | 累计AP | 相对战力 | 说明 |
|------|--------|---------|------|
| 第1转 | ~1,270 | 基础 | 初次轮回，熟悉流程 |
| 第2转 | ~2,540 | 2倍 | 开始感受到属性增长 |
| 第3转 | ~3,810 | 3倍 | 可以挑战更高境界 |
| 第4转 | ~5,080 | 4倍 | 中期玩家 |
| 第5转 | ~6,350 | 5倍 | 凡界巅峰 |
| 第6转 | ~7,620 | 6倍 | 开始进入仙界 |
| 第7转 | ~8,890 | 7倍 | 仙界中期 |
| 第8转 | ~10,160 | 8倍 | 仙界后期 |
| 第9转 | ~11,430 | 9倍 | 满转，大乘之境 |

**说明**：每次涅槃脚本本身还给额外AP（`(涅槃次数+1)×50`），实际积累更多。

## 三、境界突破流程

### 3.1 轮回修炼流程

```
选择修炼路线（境界）
    ↓
等级回到1级（属性保留）
    ↓
在对应地图从1级练到该境界上限
    ↓
达到等级上限后，可以：
  ① 继续留在当前境界刷装备/材料
  ② 突破到下一个境界（需要满足条件）
  ③ 进行涅槃（转生），获得永久AP加成，重新开始
```

### 3.2 境界突破条件

| 突破 | 条件 | 奖励 |
|------|------|------|
| 凡人→练气 | 等级≥30 + 战力≥500 | 练气称号 + 修为丹×5 |
| 练气→筑基 | 等级≥60 + 战力≥2,000 + 涅槃≥1次 | 筑基称号 + 被动技能 + 强化券 |
| 筑基→金丹 | 等级≥100 + 战力≥5,000 + 涅槃≥2次 | 金丹称号 + 高级被动技能 |
| 金丹→元婴 | 等级≥140 + 战力≥10,000 + 涅槃≥3次 | 元婴称号 + 远征队解锁 |
| 元婴→化神 | 等级≥180 + 战力≥20,000 + 涅槃≥5次 | 化神称号 + 神秘河通行证 |
| 化神→炼虚 | 等级≥210 + 战力≥50,000 + 涅槃≥6次 | 炼虚称号 + 星之力解锁 |
| 炼虚→合体 | 等级≥230 + 战力≥100,000 + 涅槃≥7次 | 合体称号 + 潜能解锁 |
| 合体→大乘 | 等级≥245 + 战力≥200,000 + 涅槃≥8次 | 大乘称号 + 装备觉醒 |
| 大乘→仙尊 | 等级≥255 + 战力≥500,000 + 涅槃≥9次 | 仙尊称号 + 终极奖励 |

### 3.3 涅槃（转生）操作

每次涅槃执行：
1. **等级回到1级**
2. **属性保留**（所有已加AP不重置）
3. **发放转生奖励**：
   - 额外AP：`(当前转生次数+1) × 50`
   - 偷学技能点 +1
   - 转生礼包（修为丹、强化券等）
4. **涅槃次数+1**
5. **全服通告**

## 四、游戏节奏设计

### 4.1 第一次轮回（新手体验）

```
Lv1 新手村 → Lv30 练气 → Lv60 筑基 → Lv100 金丹 → Lv140 元婴
                                                          ↓
                                                    第1次涅槃
                                                          ↓
                                                    回到Lv1，属性+1270
```

**体验**：完整体验凡界所有地图，感受从弱到强的过程。

### 4.2 第二~三次轮回（熟悉流程）

```
Lv1 → 快速练到Lv100+（因为属性高了，打怪更快）
    → 选择更高境界突破
    → 第2/3次涅槃，属性继续累积
```

**体验**：练级速度明显加快，可以挑战更高难度地图。

### 4.3 第四~六轮回（进入仙界）

```
Lv1 → 快速练到Lv200+（属性已经很高）
    → 进入神秘河区域
    → 解锁星之力、潜能等系统
    → 第4~6次涅槃
```

**体验**：开始接触仙界内容，装备系统逐步解锁。

### 4.4 第七~九轮回（仙尊之路）

```
Lv1 → 练到Lv255（满级）
    → 挑战终极BOSS
    → 第7~9次涅槃，属性爆炸
    → 达到仙尊境界
```

**体验**：追求极限，挑战终极内容。

## 五、关键设计优势

### 5.1 每次轮回都有意义
- 不是"重复劳动"，每次轮回属性永久增长
- 属性越高，练级越快，可以挑战更高境界
- 每次轮回都有新的境界目标

### 5.2 自然引导玩家
- 低境界在主大陆（新手友好）
- 高境界在神秘河（老玩家内容）
- 不需要强制引导，境界自然分流

### 5.3 长期目标明确
- 9次涅槃 × 9个境界 = 81个组合
- 玩家可以追求"满转满境"的终极目标
- 每次轮回都有小目标（境界突破）

### 5.4 社交性
- 同境界玩家自然组队
- 高转玩家可以带低转玩家
- 境界排行榜增加竞争性

## 六、技术实现要点

### 6.1 核心修改

1. **涅槃脚本改造** (`一键转生.js`)
   - `rebirth_level` 改为 1（回到1级）
   - 属性保留逻辑（不重置AP）
   - 境界判断和突破逻辑

2. **战力公式调整** (`战力系统.js`)
   - 增加涅槃次数权重
   - 增加等级权重（虽然等级会重置，但属性保留）

3. **境界系统新增**
   - 数据库表：`cultivation_realm`、`character_realm`
   - NPC脚本：境界突破、境界查询
   - 称号系统：境界称号显示

### 6.2 数据库设计

```sql
-- 境界配置表
CREATE TABLE cultivation_realm (
    id INT PRIMARY KEY AUTO_INCREMENT,
    realm_name VARCHAR(20) NOT NULL,      -- 境界名
    realm_order INT NOT NULL,             -- 境界顺序(1-9)
    min_level INT NOT NULL,               -- 最低等级要求
    max_level INT NOT NULL,               -- 最高等级上限
    min_reborns INT NOT NULL,             -- 最低涅槃次数
    min_combat_power INT NOT NULL,        -- 最低战力要求
    map_areas TEXT,                        -- 对应地图区域
    reward_items TEXT,                     -- 突破奖励
    description TEXT
);

-- 角色境界记录表
CREATE TABLE character_realm (
    character_id INT PRIMARY KEY,
    current_realm_id INT NOT NULL,         -- 当前境界
    realm_progress FLOAT DEFAULT 0,        -- 境界进度
    last_breakthrough DATETIME,            -- 上次突破时间
    FOREIGN KEY (character_id) REFERENCES characters(id),
    FOREIGN KEY (current_realm_id) REFERENCES cultivation_realm(id)
);
```

## 七、数值平衡参考

### 7.1 属性积累估算

假设每次涅槃练到255级：
- 基础AP：254级 × 5AP = 1,270 AP
- 涅槃脚本奖励：`(转数+1) × 50` AP
- 总计约：1,270 + 50×转数 AP

| 转数 | 基础AP | 涅槃奖励AP | 累计总AP |
|------|--------|-----------|---------|
| 1转 | 1,270 | 100 | 1,370 |
| 3转 | 3,810 | 300 | 4,110 |
| 5转 | 6,350 | 500 | 6,850 |
| 7转 | 8,890 | 700 | 9,590 |
| 9转 | 11,430 | 900 | 12,330 |

### 7.2 战力估算

假设全部加主属性（如战士加力量）：
- 1转：1,370力量 × 10 = 13,700 战力（仅属性部分）
- 5转：6,850力量 × 10 = 68,500 战力
- 9转：12,330力量 × 10 = 123,300 战力

加上装备战力，9转玩家轻松突破50万战力。
